## Electrical trade

| Term               | Meaning                                                                                                                                                                           |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **AFCI**           | Arc-fault circuit interrupter. A breaker that trips on arcing signatures. Abstracted in the game as a probabilistic trip (realism charter §3.2).                                  |
| **Ampacity**       | The current a conductor can carry continuously without exceeding its temperature rating. Taken from cited published data, never copied NEC tables.                                |
| **AWG**            | American Wire Gauge. Display-only in the game; geometry and physics use SI (mm², metres).                                                                                         |
| **CAT rating**     | A meter's overvoltage category (CAT II–IV). Part of the instrument's tool state; using a low-CAT meter on service equipment is a safety violation.                                |
| **EGC**            | Equipment grounding conductor: the bare or green wire that bonds metal parts so a fault trips the breaker. A lost EGC leaves an enclosure live during a fault.                    |
| **FLA**            | Full-load amps, from a motor nameplate. Overload relays are set to FLA, not to the breaker rating.                                                                                |
| **GEC**            | Grounding electrode conductor: connects the service to the ground rod or other electrode.                                                                                         |
| **GFCI**           | Ground-fault circuit interrupter. Trips when residual current exceeds about 5 mA (NEC profile).                                                                                   |
| **Ghost voltage**  | A misleading reading on a high-impedance (10 MΩ) meter caused by capacitive coupling to an open conductor. Emerges from the solver because the meter is stamped into the circuit. |
| **LoZ**            | Low-impedance meter mode (about 3 kΩ) that loads the circuit and makes ghost voltage disappear.                                                                                   |
| **LOTO**           | Lockout/tagout: isolating, locking and verifying zero energy before work. A mechanic, not a cutscene.                                                                             |
| **Live–dead–live** | Testing a meter on a known live source, then the de-energised circuit, then the live source again. Tracked by the safety system.                                                  |
| **MWBC**           | Multiwire branch circuit: two hots sharing one neutral. Losing the neutral causes overvoltage on one leg.                                                                         |
| **NEC**            | National Electrical Code (NFPA 70), the US installation code. The game paraphrases requirements and cites article numbers; it never reproduces NEC text or tables.                |
| **OCPD**           | Overcurrent protective device: a breaker or fuse.                                                                                                                                 |
| **Single-phasing** | A three-phase motor losing one phase. It hums, draws high current on the remaining phases and should trip its overload.                                                           |
| **Split-phase**    | The residential US service: 120/240 V from a centre-tapped transformer.                                                                                                           |

## Controls and automation

| Term                  | Meaning                                                                                                      |
| --------------------- | ------------------------------------------------------------------------------------------------------------ |
| **4–20 mA**           | The analog current-loop standard. 4 mA is the live zero; a broken loop reads 0 mA.                           |
| **FBD**               | Function Block Diagram, an IEC 61131-3 language (P11).                                                       |
| **HMI**               | Human-machine interface: an operator screen bound to PLC tags (P12).                                         |
| **Ladder logic (LD)** | The relay-diagram-style PLC language, with instructions such as XIC, XIO, OTE and TON (P10).                 |
| **PLC**               | Programmable logic controller. Each simulated PLC runs in its own worker, scanning on sim-clock ticks (P10). |
| **PLCopen TC6 XML**   | The open interchange format for IEC 61131 programs; used for import/export.                                  |
| **PNP / NPN**         | Sourcing / sinking transistor sensor outputs. A PNP sensor on a sinking input card never turns the input on. |
| **SCADA**             | Supervisory control and data acquisition: plant-wide HMI, alarms and trends (P12).                           |
| **Scan cycle**        | A PLC's loop: read inputs → execute program → write outputs → housekeeping.                                  |
| **ST**                | Structured Text, the Pascal-like IEC 61131-3 language (P11).                                                 |

## Simulation

| Term                 | Meaning                                                                                                                                                          |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **gmin**             | A tiny conductance from every node to ground so islanded sections still produce a solvable matrix.                                                               |
| **Island**           | A set of nodes connected to each other but not to the rest of the circuit. DC and AC islands are solved separately.                                              |
| **MNA**              | Modified nodal analysis: the standard way to assemble circuit equations into a matrix. Controls uses real-valued MNA for DC and complex phasor MNA for 60 Hz AC. |
| **Netlist**          | The electrical graph (nodes and branches) compiled from the physical as-built wiring.                                                                            |
| **Netlist compiler** | The `sim-core` step that union-finds connected terminals and turns conductors and terminations into impedance stamps (P2).                                       |
| **Oracle test**      | A test comparing `sim-core` results with ngspice on random small circuits (P2).                                                                                  |
| **Phasor**           | A complex number representing a sinusoid's magnitude and phase at a fixed frequency. Lets the AC solver skip time-stepping.                                      |
| **Quasi-static**     | Solving steady-state phasors at each update rather than a full time-domain transient. See [ADR 0002](decisions/0002-simulation-architecture.md).                 |
| **Stamp**            | A device's contribution to the MNA matrix. Meters are stamped too, which is why readings are truthful.                                                           |
| **Tick**             | One integer step of sim time (1 kHz). Sim time is always an integer tick count for determinism.                                                                  |
| **Union-find**       | A disjoint-set structure used to merge terminals joined by wires and closed contacts before matrix assembly.                                                     |

## Game and codebase

| Term                            | Meaning                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Argument form**               | The palette's form for a command's arguments, generated from its Zod `args` through `z.toJSONSchema` (`buildArgForm` in `@controls/feature-palette`). **Arg hints** are `.meta()` keywords that only label or explain a field (`title`, `description`) or mark a reference (`x-controls-ref: entity`, which offers the selection); they never change what the schema accepts.                                                                                                                                   |
| **As-built**                    | The physical wiring the player (or job author) actually installed. The simulator runs the as-built, not the print.                                                                                                                                                                                                                                                                                                                                                                                              |
| **Assisted**                    | A world flag set once a cheat command has run (palette, console or script). It persists in the save and is never cleared; assisted runs are excluded from career scoring.                                                                                                                                                                                                                                                                                                                                       |
| **BVH**                         | Bounding volume hierarchy: a tree of nested boxes that makes ray picking logarithmic instead of testing every triangle. The renderer uses three-mesh-bvh: an `ObjectBVH` over selectable objects, then a `MeshBVH` per geometry.                                                                                                                                                                                                                                                                                |
| **Catalogue reference**         | How a save points at a device or prop: `{ id, version }` (e.g. `prop.crate` at version 1), never an inlined copy, so catalogue fixes reach old saves.                                                                                                                                                                                                                                                                                                                                                           |
| **`catalogVersion`**            | Version of the device catalogue in `content/`. Versioned independently of the app.                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Command**                     | A registered, Zod-typed action (`entity.place`, `view.resetLayout`). The only way the world changes; shared by the palette, keybinds, console and scripting API. Its `run` is pure and returns an apply/invert pair, nothing, or a refusal ([ADR 0006](decisions/0006-command-system.md)).                                                                                                                                                                                                                      |
| **Command bus**                 | `CommandBus` in `@controls/commands`: runs commands by id, keeps the undo and redo stacks and appends each successful command to the replay log.                                                                                                                                                                                                                                                                                                                                                                |
| **Command palette**             | The searchable list of every registered command (Ctrl+K or Ctrl+Shift+P, the `palette.open` command): fuzzy search over title, category and id, recent commands first, unavailable commands shown with the reason, and an argument form for commands that take arguments (F1.3).                                                                                                                                                                                                                                |
| **Console line**                | One line of the dev console's `verb.noun --flag value` syntax (`entity.delete 3`, `entity.move 1 --positionMm.x 150 …`). Positional words fill a command's args in key order, dotted flags fill nested fields, and the command's Zod schema validates the result. A **console-line file** (`.console`) is a script made of them: data, so it runs in the game as well as in `sim-cli` ([ADR 0008](decisions/0008-console-and-scripts.md)).                                                                      |
| **Context argument**            | A command argument a keybinding takes from a context key when the key is pressed (`entity.delete.selection` takes `id` from `selection.entityId`). The binding fires only while the key is set, and the log records the concrete value (ADR 0006, F1.7).                                                                                                                                                                                                                                                        |
| **Context expression (`when`)** | A small boolean expression on a command (`mode == 'work' && selection.kind == 'terminal'`) that tells the palette and keybindings whether to offer it. Parsed by hand (no `eval`); advisory, so `exec` never checks it (ADR 0006).                                                                                                                                                                                                                                                                              |
| **`.ctrl`**                     | The save file: a ZIP of JSON documents with a manifest. See [ADR 0004](decisions/0004-save-format.md).                                                                                                                                                                                                                                                                                                                                                                                                          |
| **Dev console**                 | The in-game text surface for commands (`@controls/feature-console`, F1.5), docked in the workspace's bottom panel and toggled with backtick (`console.toggle`). Available in Sandbox and dev builds (the `console.available` context key). It runs console lines through the one registry, with Tab completion, history in settings, `help`, `world.hash` and `run` for console-line files ([architecture](architecture/console.md)).                                                                           |
| **Docking workspace**           | The in-game layout: the 3D viewport plus docked panels (inspector on the right, console at the bottom), resized with keyboard-operable splitters. Custom split panes, not dockview ([ADR 0005](decisions/0005-docking-workspace.md)).                                                                                                                                                                                                                                                                           |
| **`extensions` bag**            | A JSON object on the world, each entity, the manifest and settings for data the current schema doesn't model. It must round-trip untouched.                                                                                                                                                                                                                                                                                                                                                                     |
| **Fixture**                     | A checked-in example document for a given `schemaVersion` (`libs/domain/save-format/fixtures/`). Every fixture of every version must load forever.                                                                                                                                                                                                                                                                                                                                                              |
| **Four-surface scenario**       | The P1 acceptance scenario (place, move, rotate, delete, undo, redo) driven through every surface and required to reach one pinned `world.hash`. Headless drivers (scripting API, TypeScript script, console-line file, replay) run in `sim-cli`'s tests; mouse, palette and console in `apps/game-e2e`.                                                                                                                                                                                                        |
| **Gesture intent**              | What the renderer emits at a gesture's commit point (`place`, `move`, `cancelPlacement`). `feature-workspace` executes each `place` or `move` as exactly one `entity.place` or `entity.move`; dragging produces none (F1.7).                                                                                                                                                                                                                                                                                    |
| **Ghost**                       | The translucent placement preview of the prop being placed or moved, at the snapped position. Renderer-local view state: not pickable, never in the world, and hidden when the cursor is on no valid snap.                                                                                                                                                                                                                                                                                                      |
| **HUD**                         | Heads-up display over the viewport: interaction mode, selection summary and the assisted badge.                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **Input action**                | A rebindable, viewport-local input such as `input.moveForward`, `input.selectNext` or `input.commitPlacement`, keyed by physical key code and declared in `INPUT_ACTIONS` (`@controls/commands`). Handled by the renderer and never a Command, so per-frame input never enters the replay log (ADR 0006). Switching mode and focusing became Commands (`view.mode`, `view.focus`) in F1.7.                                                                                                                      |
| **Interaction mode**            | Walk (first-person), Work (focused orbit/pan with a cursor) or Editor (a 2D editor docked beside the viewport). Plan §4.9.                                                                                                                                                                                                                                                                                                                                                                                      |
| **Key chord**                   | Modifiers plus one key, written `Mod+Shift+Z`. `Mod` is Ctrl, or Cmd on macOS. The canonical form (`normaliseChord`) is what settings store and key presses resolve to (ADR 0006, "Keybindings").                                                                                                                                                                                                                                                                                                               |
| **Keybinding**                  | A chord bound to a command (with fixed arguments, or arguments from context keys) or an input action, under a **binding id** (`edit.undo`, `toolbelt.select.slot3`, `view.mode.walk`, `entity.delete.selection`, `input.moveForward`). Defaults come from `CommandDef.keybinding`, `CommandDef.bindings` and `INPUT_ACTIONS`; player overrides live in settings `controls.keybindings`. Two bindings on one chord whose `when`s are not provably disjoint are a **conflict**, shown in the Key bindings dialog. |
| **Main menu**                   | The start screen (New sandbox, Continue, Load, Settings, About, Quit), drawn over the live 3D viewport. Escape in the workspace returns to it, with Resume.                                                                                                                                                                                                                                                                                                                                                     |
| **Migration chain**             | The pure `n → n+1` steps that upgrade any older document to the current `schemaVersion`. Total: every known version reaches the current one.                                                                                                                                                                                                                                                                                                                                                                    |
| **Print**                       | A schematic, wiring diagram or panel layout. A separate document that may be wrong.                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Realism charter**             | Plan §3: simulate what can be measured, abstract what can't, cite a `source` for every constant.                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Region profile**              | The bundle of voltages, frequency, sizing units, colours, symbols and rules for a code region. NEC only through 1.0.                                                                                                                                                                                                                                                                                                                                                                                            |
| **Replay log**                  | The ordered list of successfully executed commands (`seq`, `tick`, `id`, `args`), including undo, redo and view commands. Replaying it from its initial world through a fresh bus reproduces the session's world hash exactly.                                                                                                                                                                                                                                                                                  |
| **Reticle**                     | The screen-centre aim point: the walk-mode crosshair, and the ghost's aim whenever the mouse pointer isn't over the canvas, so placement works from the keyboard (Enter commits).                                                                                                                                                                                                                                                                                                                               |
| **`schemaVersion`**             | Integer version of the save format, driving the migration chain.                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Scripting API**               | `@controls/scripting-api`: the typed `Game` object (`exec`, `world()`, `hash()`, `on()`, `replayLog()`) over the one command registry. `sim-cli` scripts drive it and the UI's `Session` wraps it, so both run identical code. `probe` (P2) and `tag` (P10) are reserved.                                                                                                                                                                                                                                       |
| **Selection**                   | The object the player has picked in the viewport (`selection.kind` is its kind). Renderer/UI state, not world state: never saved or logged.                                                                                                                                                                                                                                                                                                                                                                     |
| **Settings document**           | The player's preferences (graphics, audio, controls, units, default difficulty, region, theme, workspace layout). Separate from saves, with its own `settingsVersion` (F1.8a).                                                                                                                                                                                                                                                                                                                                  |
| **`settingsVersion`**           | Integer version of the settings document, independent of the save's `schemaVersion`.                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Snap target**                 | A surface placement can snap to: a DIN rail (18 mm modules), a backplate grid (5 mm) or a stud wall (16 in centres). The maths lives in `@controls/world-model` (`snap/`), takes and returns integer mm, and returns the footprint's lower-left anchor, which becomes the entity's `positionMm`. `snapToBest` picks the most specific target under the cursor (rail, then plate, then wall).                                                                                                                    |
| **Stream key**                  | The stable label (`command:<seq>`, `entity:<id>`) mixed with the world seed to derive an independent sfc32 random stream, so no generator state is ever saved (ADR 0006, ADR 0007).                                                                                                                                                                                                                                                                                                                             |
| **Tool belt**                   | Nine slots, each holding a placeable prop in P1 (settings `toolBelt.slots`). Keys 1–9 run `toolbelt.select {slot}`, a view command; the active slot is UI state, shown in the HUD and published as the `toolbelt.slot` context key. The viewport places the active slot's prop (F1.7); Escape puts the tool away without a command.                                                                                                                                                                             |
| **Undo stack**                  | The apply/invert pairs of undoable commands, newest on top. `edit.undo` moves the top change to the redo stack; any new world change clears redo. Never saved: a loaded game starts with an empty history.                                                                                                                                                                                                                                                                                                      |
| **View command**                | A command that never changes the world or its hash (`view.resetLayout`, `toolbelt.select`, `view.mode`, `view.focus`, `palette.open`). Usually logged (`view.mode` and `view.focus` are: they change what the player sees); UI chrome such as `palette.open` is `logged: false` and never enters the replay log (an **unlogged command**). Declared in domain code so headless replay knows it; the UI applies its effect when the session reports it ran.                                                      |
| **Walk mode**                   | First-person camera: WASD plus mouse look with pointer lock (Esc releases it), clamped to the room at eye height. Entered with `view.mode walk` (V).                                                                                                                                                                                                                                                                                                                                                            |
| **Web harness**                 | The browser build of `apps/game` (`pnpm start:web`) using `@controls/platform-web`. For development and Playwright, not a shipped product.                                                                                                                                                                                                                                                                                                                                                                      |
| **Work mode**                   | Focused camera: orbit and pan with limits around a backplate, rail, wall or bench (`view.focus --target <id>`, F), with a pointer for picking, placement and drag-to-move.                                                                                                                                                                                                                                                                                                                                      |
| **World document**              | The persistent, serialisable game state (physical model, prints, PLC and HMI documents).                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **World hash**                  | `world.hash`: SHA-256 (pure TypeScript, from FIPS 180-4) of the canonical JSON (sorted keys, normalised `-0`) of the world document, as lower-case hex. The same commands from any surface give the same hash, in Node and Chromium alike (ADR 0007).                                                                                                                                                                                                                                                           |

## Workspace and tooling

| Term                      | Meaning                                                                                                                                                                                                                                       |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ADR**                   | Architecture decision record, in [`docs/decisions/`](decisions/).                                                                                                                                                                             |
| **`app://`**              | The custom Electron protocol serving the Angular build. Used instead of `file://` so it can send COOP/COEP and CSP headers.                                                                                                                   |
| **CDP attach**            | How `apps/desktop-e2e` tests a packaged build: it starts the binary with `--remote-debugging-port` and connects over the Chrome DevTools Protocol, because the Fuses block Playwright's `_electron`. Selected with `CONTROLS_E2E_EXECUTABLE`. |
| **COOP / COEP**           | Cross-Origin-Opener-Policy and Cross-Origin-Embedder-Policy headers. Together they make a page `crossOriginIsolated`.                                                                                                                         |
| **`crossOriginIsolated`** | A browser flag that must be true for `SharedArrayBuffer` to exist.                                                                                                                                                                            |
| **DoD**                   | Definition of Done: the checklist every feature PR meets (plan §9.1, [`CLAUDE.md`](../CLAUDE.md)).                                                                                                                                            |
| **electron-builder**      | Packages the app into installers (NSIS, dmg/zip, AppImage/deb/rpm) and writes `latest*.yml` update metadata.                                                                                                                                  |
| **electron-updater**      | Reads `latest*.yml` from GitHub Releases and applies updates.                                                                                                                                                                                 |
| **Fuses**                 | Electron build-time switches (`@electron/fuses`). Controls disables RunAsNode, `NODE_OPTIONS` and the Node CLI inspect flags, and enables cookie encryption, embedded ASAR integrity and OnlyLoadAppFromAsar.                                 |
| **Module boundaries**     | Nx lint rule `@nx/enforce-module-boundaries` checking imports against project tags (`type:domain` etc.).                                                                                                                                      |
| **`pnpm verify`**         | The one command that runs exactly what CI runs (CI then also runs the e2e suites).                                                                                                                                                            |
| **Preload entry**         | `@controls/ipc-contract/preload`: the narrow import for the sandboxed preload, with channel names and the bridge type only (no Zod).                                                                                                          |
| **SAB**                   | `SharedArrayBuffer`: memory shared between the renderer and workers; used for sim snapshots (P2).                                                                                                                                             |
| **`sim-cli`**             | `apps/sim-cli` (`scope:headless`): runs the game headless in plain Node. `pnpm sim run <script>` (a TypeScript module or a console-line file), `pnpm sim replay <log>` and `pnpm sim hash <world>` print `world.hash`.                        |
| **Smoke test**            | `apps/desktop-e2e`: launches the real Electron app and checks `app://`, the version, cross-origin isolation, the CSP, the sandbox and that the viewport starts.                                                                               |
| **Zoneless**              | Angular without zone.js. Change detection runs only when signals change.                                                                                                                                                                      |
