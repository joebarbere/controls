# @controls/feature-workspace

The docking workspace (`type:feature`): `ctl-workspace` (3D viewport, inspector and bottom panel with keyboard-operable splitters), the `ctl-viewport` host for `@controls/renderer`, and the serialisable `WorkspaceLayout` (`DEFAULT_WORKSPACE_LAYOUT`, `normaliseLayout`). Custom split panes, not dockview: see [ADR 0005](../../../docs/decisions/0005-docking-workspace.md).

Tests: `pnpm nx test feature-workspace`.
