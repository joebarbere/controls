# @controls/feature-shell

The game shell (`type:feature`): `ctl-main-menu`, `ctl-about-dialog` (keeps the `about-*` e2e test ids), `ctl-hud`, `ctl-notifications` + `NotificationService`, and `ShellState` (which screen and dialog are showing; UI-only state).

Tests: `pnpm nx test feature-shell`. See [UI shell architecture](../../../docs/architecture/ui-shell.md).
